# Фото для сайта

Положите сюда фотографии из группы ВК (https://vk.com/eucalipt_balakovo) с такими именами —
сайт сам подставит их вместо временных картинок. Формат `.jpg`, ширина 1200–2000 px.

| Файл | Где на сайте |
|---|---|
| `hero.jpg` | Главный экран (большой букет, горизонтальное фото) |
| `hit-1.jpg` … `hit-9.jpg` | Карточки каталога (почти квадратные) |
| `band-1.jpg`, `band-2.jpg`, `band-3.jpg` | Ленты «Креатив / Эстетика / Качество» (широкие) |
| `about-1.jpg`, `about-2.jpg` | Блок «О нас» (флорист, мастерская, зелень) |
| `work-1.jpg` … `work-7.jpg` | Галерея «Наши работы» |

Если файла нет — показывается временное фото, а без интернета — мягкий градиент.
