# Эвкалипт — сайт цветочного магазина (Балаково)

Одностраничный сайт: `index.html` (без сборки, открывается в браузере, подходит для GitHub Pages).

- Контакты, адрес, часы и ссылки на карты — блок `CONFIG` внизу `index.html`.
- Фото — папка `img/`, имена файлов в `img/README.md`.
- Фото и контакты взяты из группы ВК.
- `eucalipt-standalone.html` — тот же сайт одним файлом, фото встроены внутрь (можно отправить или открыть без папки img).
- Прежняя страница «Капитал до 30» перенесена в `kapital-do-30.html`.
