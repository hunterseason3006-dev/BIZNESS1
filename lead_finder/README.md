# lead_finder

Два инструмента для поиска организаций. Только юрлица и организации из карт, без ФИО физлиц.

## Сайт

```bash
pip install -r requirements.txt
python -m lead_finder.web          # открыть http://127.0.0.1:5000
```

Две вкладки: «Карты: без сайта» (категория, город, ключ API) и «ЕГРЮЛ» (загрузка zip/xml, ОКВЭД, регион).
Результат — таблица на странице и кнопка «Скачать CSV». Ключ API не сохраняется.
То же самое доступно из командной строки:

## 1. Организации без сайта (2ГИС / Яндекс Карты)

Ключи API: 2ГИС — <https://dev.2gis.ru>, Яндекс Карты (Places) — <https://developer.tech.yandex.ru>.

```bash
export TWOGIS_API_KEY=...          # или YANDEX_MAPS_API_KEY=...
python -m lead_finder.maps --source 2gis --query "стоматология" --city "Казань" --out out/dental.csv
```

Что делает: ищет по запросу в городе, выкидывает организации с указанным сайтом и дубликаты,
по умолчанию оставляет только с телефоном (`--allow-no-phone` снимает ограничение).
В колонке `socials` видно, есть ли у организации VK, Telegram и т.п. — без сайта, но с соцсетями.

## 2. Юрлица из ЕГРЮЛ по ОКВЭД и региону

Открытые данные ФНС: <https://data.nalog.ru/opendata/> — скачать архив ЕГРЮЛ (zip с XML).

```bash
python -m lead_finder.egrul --source egrul_xml.zip --okved 86.23 96.02 --region 16 --out out/dental_inn.csv
```

- `--okved` — префиксы основного ОКВЭД (`86.2` вернёт все подкатегории 86.2x).
- `--region` — коды регионов (77 — Москва, 16 — Татарстан).
- ЕГРЮЛ не содержит телефонов. Имея ИНН/название, сверяй с картами (пункт 1) по названию.
- ИП не выгружаются: в реестре у них ФИО.

## Тесты

```bash
python -m unittest discover -s lead_finder/tests -t .
```

Тесты работают на фикстурах. Формат ответов API 2ГИС/Яндекса и XML ФНС проверен по документации
и первому реальному запуску ещё не сверен — при расхождении поправь поля в `from_2gis` / `from_yandex` / `parse_entity`.
